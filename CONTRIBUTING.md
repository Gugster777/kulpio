# Contributing Guidelines

Thank you for your interest in contributing to **kulpio**! Whether you are fixing a bug, improving documentation, or proposing new features, all contributions are greatly appreciated.

---

## How to Contribute

You can contribute to the project in several ways:
1. **Report Bugs**
2. **Suggest New Features**
3. **Improve Documentation**
4. **Submit Code via Pull Requests**

---

## Submitting Issues

Before creating a new issue:
- Please check existing [Issues](../../issues) to see if the topic is already being discussed.
- When reporting a bug, please include:
  - Clear steps to reproduce the issue.
  - Expected vs. actual behavior.
  - Your operating system and environment/dependency versions.

---

## Pull Request Workflow

If you would like to contribute code:

1. **Fork** the repository.
2. **Create a new branch** for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
   # or for bug fixes:
   git checkout -b fix/your-bug-fix
